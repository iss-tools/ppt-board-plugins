# Vue Canvas Plugins

This directory contains the official plugins for `vue-canvas`, extending its capabilities with AI generation, real-time collaboration, advanced UI components, and more.

## Available Plugins

| Plugin | Description |
|--------|-------------|
| **plugin-ai** | AI integration plugin. Features include AI provider configuration, prompt management (with detailed style settings), and an AI chat interface to generate and modify canvas content. |
| **plugin-cooperation** | Real-time collaboration plugin powered by Ably. Supports multi-user editing, read-only mode, and end-to-end encrypted data synchronization. |
| **plugin-menu** | Enhances the main menu and toolbar of the canvas editor. |
| **plugin-my-library** | A personal material library for managing user assets and components. |
| **plugin-storage** | Storage management plugin for saving, loading, and managing canvas data. |
| **plugin-style-props** | Advanced style properties configuration panel for canvas elements. |

## Documentation

For more detailed requirements and planning, please check the [docs](./docs) directory.

## Development

These plugins are built using Vue 3, TypeScript, and Naive UI. They are designed to be integrated seamlessly into the `vue-canvas` core architecture, providing a highly customizable and extensible editing experience.
