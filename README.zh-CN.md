# Vue Canvas 插件集合

本目录包含了 `vue-canvas` 的官方扩展插件，通过引入 AI 生成、实时协同、高级 UI 组件等功能，极大地扩展了画布引擎的能力。

## 可用插件列表

| 插件名称 | 功能描述 |
|--------|-------------|
| **plugin-ai** | AI 辅助设计插件。提供大模型供应商(Provider)配置、提示词管理（支持分辨率、风格等各种细化参数配置）、以及通过 AI 聊天直接生成和局部修改画布内容的功能。 |
| **plugin-cooperation** | 基于 Ably 的实时协同插件。支持多用户实时编辑、只读模式，并采用端到端加密技术来保障实时数据同步的安全。 |
| **plugin-menu** | 增强版画布主菜单与工具栏。 |
| **plugin-my-library** | 个人素材库插件，用于管理用户自定义的资产与组件。 |
| **plugin-storage** | 存储管理插件，负责画布数据的持久化保存、加载与管理。 |
| **plugin-style-props** | 高级样式属性配置面板插件，用于精细调节画布元素的样式。 |

## 架构与开发

本目录下所有插件均基于 Vue 3、TypeScript 和 Naive UI 进行开发。它们被设计为可以与 `vue-canvas` 核心（core）进行无缝集成，旨在为开发者提供一个高度可定制且易于扩展的编辑体验。
